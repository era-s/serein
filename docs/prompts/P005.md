# P005 · 모든 데스크탑 배경화면 적용

- 접수일: 2026-09-06
- 관련 요청: [P001](P001.md), [P002](P002.md), [P004](P004.md)

## 사용자 요청 원문

> 지금 desktop2 배경화면만 바뀌는데, 내가원하는건 모든 배경화면이 다 변하는 것이다.

## 구현 결정

- 물리 디스플레이뿐 아니라 Mission Control의 모든 데스크탑(Space)에 같은 배경화면을 적용한다. 수동 적용과 캘린더·주간·오늘 표시 자동 갱신 모두 같은 경로를 사용한다.
- Apple 공개 NSWorkspace API의 현재 Space 한정을 확인하고, 모든 Space에 적용하는 경로는 별도로 검증한다. 이전 시스템 배경화면 설정은 로컬 백업하고 화면 보호기 설정은 보존한다.
- 프롬프트별 구현 및 실제 검증 결과는 [개발 기록](../devlog.md)과 `Prompt-ID: P005` 커밋으로 기록한다.
