# P011 · macOS 27 배경화면 적용 복구

- 접수일: 2026-09-16
- 관련 요청: [P001](P001.md), [P002](P002.md), [P005](P005.md), [P010](P010.md)

## 사용자 요청 원문

> mac os 27에서 지금 배경화면 적용이 안되고 있어 이걸 해결해봐

## 원인과 구현 방향

- 실제 앱의 오류와 회귀 검사에서 macOS 27이 지원 버전 목록에 없어 전체 Space 적용을 거부함을 확인했다.
- 로컬 macOS 27 저장소의 이미지 형식이 기존 macOS 26 방식과 일치함을 확인한 뒤 27을 해당 읽기·쓰기·검증 경로에 추가한다.
- 미지원 후속 버전과 잘못된 저장 형식은 계속 거부하며 백업·화면 보호기 보존·동시 변경 검사·실패 복구를 유지한다.
- 실제 개인 시간표와 시스템 저장소 원본은 로컬 검증에만 사용하고 공개 저장소에는 포함하지 않는다.
