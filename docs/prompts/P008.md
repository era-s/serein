# P008 · 요일 옆 숫자 표시 방식

- 접수일: 2026-09-08
- 관련 요청: [P001](P001.md), [P002](P002.md), [P003](P003.md), [P004](P004.md), [P005](P005.md), [P006](P006.md), [P007](P007.md)

## 사용자 요청 원문

> 캘린더와 연동된 경우에는 요일 옆 숫자가 그냥 01 02 이렇게 되는게 아니라 실제 날짜로 저장하게 수정하라. 이것도 옵션으로 넣어라. 아에 숫자를 뺄 수도 있게 만들어보자.

## 구현 방향

- 디자인에서 순서 번호·실제 날짜·표시 안 함을 선택한다.
- 별도 선택이 없으면 캘린더 연결은 실제 날짜, 직접 입력 시간표는 기존 순서 번호를 사용한다. 사용자가 명시적으로 고른 옵션은 재실행·재가져오기·주간 갱신에도 유지한다.
- 실제 날짜는 연결한 주와 시간대에서 계산하고 `MM.dd`로 표시한다. 지난주를 유지하는 경우 지난주의 날짜를 표시하며, 오늘 표시와 독립적으로 동작한다.
- 미리보기·PNG 저장·수동/자동 배경화면 적용에 같은 코드 기반 렌더 입력을 사용한다. 개인 일정·숨김·권한·자동화 옵션을 보존한다.
