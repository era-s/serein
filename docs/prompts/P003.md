# P003 · Google Calendar와 Apple 캘린더 연동

- 접수일: 2026-09-06
- 관련 요청: [P001](P001.md), [P002](P002.md)

## 사용자 요청 원문

> 추가로 google clander 또는 애플 캘린더 연동해서 만드는것도 만들자

## 구현 결정

- macOS EventKit을 사용해 Apple 캘린더에 연결된 iCloud·Google 계정의 일정을 가져온다. Google은 시스템 인터넷 계정에서 캘린더 동기화를 활성화한다.
- 사용자가 연결을 누를 때 캘린더 접근을 요청한다. 원본 캘린더에 쓰거나, 앱 실행 시 권한을 요청하지 않는다.
- 캘린더와 월요일부터 일요일까지의 주간 범위를 선택하고, 실제 시간과 장소를 검토한 뒤 시간표에 반영한다.
- 종일 일정은 시간표에서 제외하고 개수를 알린다. 자정을 넘는 일정은 요일별로 나눈다.
- 현재 연결 상태를 다시 읽는 가져오기 기능이며, 배경에서 배경화면을 자동 갱신하는 기능은 아니다.
