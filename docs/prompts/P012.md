## 사용자 요청 원문

> 우리 프로젝트가 종료하면 상단 바에만 표시되고 dock에는 표시 안되게 할 수 있나? 추가로 전력을 최대한 덜 먹었으면 좋겠어

## 제안과 사용자 승인

창을 닫으면 메뉴 막대에서 자동화를 유지하고 Dock에서 숨긴다. 다시 열면 창과 Dock을 복원한다. 매분 검사 대신 캘린더 변경·날짜 전환·잠자기 복귀 알림을 사용하고, 닫힌 창의 미리보기 렌더링을 생략한다. 메뉴의 ‘Serein 종료’와 ⌘Q는 완전 종료로 유지한다.
