# P004 · 주간 캘린더 변경·오늘 표시·주간 자동 교체

- 접수일: 2026-09-06
- 관련 요청: [P001](P001.md), [P002](P002.md), [P003](P003.md)

## 사용자 요청 원문

> 추가 기능을 구현한다. 만약 캘린더에 변경된 일정이 있다면 (당연히 이번 주 한정) 자동으로 배경화면을 교체하도록 만들어라. 이건 옵션으로 키고 끌 수 있어야 한다. 또한 오늘을 미세하게 배경화면에서 표시 (테두리 같은걸로)하고 한 주마다 자동으로 배경화면을 교체하는 기능도 옵션으로 넣어라. 아마 이걸 가장 자주 사용할 것이다.

## 구현 결정

- 이번 주 일정 변경 시 교체, 오늘 열 표시, 매주 월요일 교체를 각각 켜고 끌 수 있게 한다. 자동 교체는 기본 꺼짐으로 두고 연결한 캘린더와 대상 디스플레이를 저장한다.
- 이벤트 알림과 주기 확인, 날짜 전환, 잠자기 해제에 대응한다. 이번 주 내용이 같으면 불필요한 PNG 생성/교체를 하지 않는다.
- 오늘 표시는 현재 날짜에서 계산한 요일을 렌더러의 명시적 입력으로 전달한다. 렌더러는 시계에 직접 접근하지 않는다.
- 메뉴 막대에서 실행 상태를 확인하고 창을 닫아도 작동하게 한다. 로그인 시 실행도 사용자가 선택할 수 있도록 제공한다.
- 실제 적용·권한·로그인 설정은 개발 검증에서 대신 활성화하지 않고, 가짜 캘린더·적용기로 조건을 검증한다.
