# P002 · 비공개 GitHub 개발 기록과 프롬프트 추적

- 접수일: 2026-09-06
- 관련 제품 요청: [P001](P001.md)

## 사용자 요청 원문

> 중간중간 개발과정을 github에 private repo 만들어서 기록하고 특정 프롬프트로 만든 결과물이 이거다 라는걸 알 수있도록 함께 기록할 수 있는 스킬 또는 도구를 이용해줘.

## 구현 결정

- GitHub CLI로 비공개 저장소를 만들고 의미 있는 개발 단계마다 커밋과 push로 기록한다.
- 재사용 가능한 [prompt-ledger 스킬](../../.agents/skills/prompt-ledger/SKILL.md)을 이 저장소에도 보관한다.
- 프롬프트 원문, 구현 결정, 실제 검증을 분리해서 기록한다.
- 커밋의 `Prompt-ID` 트레일러로 프롬프트와 정확한 결과 스냅샷을 연결한다.
- 스크린샷 등 결과물은 [개발 기록](../devlog.md)에 상대 링크로 연결한다. 입력 참조 이미지는 자동으로 저장소에 복사하지 않는다.

## 결과 확인

실제로 완료한 단계는 [개발 기록](../devlog.md)에서 확인한다.

```sh
git log --all --extended-regexp --grep='^Prompt-ID: P002$' --format='%h %s'
```
