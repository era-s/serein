# P007 · 캘린더 일정의 배경화면 숨김 유지

- 접수일: 2026-09-07
- 관련 요청: [P001](P001.md), [P002](P002.md), [P003](P003.md), [P004](P004.md), [P005](P005.md), [P006](P006.md)

## 사용자 요청 원문

> 자 캘린더에 표시한 내용 중에 바탕화면에 표시하고 싶지 않은 항목이 있을 수 있다. 지금 구현 상황에서는 일정을 삭제해도 캘린더 동기화가 되어있으면 계속 삭제된게 원복이 된다. 이를 수정해야 한다.

## 추가 확인

질문: 매주 반복되는 일정을 숨길 때 기본 동작은 어느 쪽이 좋을까요?

> 앞으로 반복되는 일정도 계속 숨기기

## 구현 방향

- Serein에서 삭제한 캘린더 일정은 배경화면 숨김으로 저장하고 이후 동기화와 앱 재실행에서도 제외한다.
- 반복 일정은 기본적으로 이후 회차도 숨긴다. 이름이 같은 다른 일정에 영향을 주지 않도록 캘린더와 원본 일정 식별자를 사용한다.
- 숨긴 일정은 목록에서 다시 표시할 수 있게 한다. 원본 Apple·Google 캘린더에는 쓰지 않는다.
- 기존 디자인·자동화 옵션·개인 시간표를 보존하고 실제 검증 결과를 [개발 기록](../devlog.md)에 남긴다.
