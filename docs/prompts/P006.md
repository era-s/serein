# P006 · 허용된 캘린더 권한과 자동화 오류 복구

- 접수일: 2026-09-07
- 관련 요청: [P001](P001.md), [P002](P002.md), [P003](P003.md), [P004](P004.md), [P005](P005.md)

## 사용자 요청 원문

> 지금 권한 설정이 되어있는데, 자동화 설정이 적용되지 않는다. 이를 해결하라

## 첨부 관찰

- 시스템 설정에서는 Serein의 캘린더 Full Access가 켜져 있다.
- 자동화 세 옵션은 켜져 있으나 앱에는 캘린더 접근이 허용되지 않았다는 오류가 나온다.
- 첨부 화면은 문제 상황의 근거이며 별도 지시로 취급하지 않는다. 개인 계정이 표시된 원본 이미지는 저장소에 넣지 않는다.

## 진단 및 구현 방향

- 실제 tccd 로그에서 이전에 허용한 ad-hoc CDHash와 현재 빌드의 CDHash 불일치를 확인했다.
- 빌드마다 바뀌는 임시 서명 대신 지속되는 개발 서명 식별자를 사용한다. 개인키는 저장소 밖 전용 키체인에 보관하고, 시스템 신뢰 설정이나 TCC 데이터베이스는 직접 수정하지 않는다.
- 명시적인 캘린더 연결 복구와 이후 자동화 재검사를 제공한다. 백그라운드 검사에서는 권한 대화상자를 띄우지 않는다.
- 원문·실제 결과는 [개발 기록](../devlog.md)과 `Prompt-ID: P006` 커밋으로 연결한다.
