## M006 · 주간 자동화와 오늘 표시 · 2026-09-06

- 프롬프트: [P001](prompts/P001.md), [P002](prompts/P002.md), [P003](prompts/P003.md), [P004](prompts/P004.md)
- 결과: [자동화 엔진](../Sources/TimetableWallpaper/WallpaperAutomation.swift), [옵션 화면](../Sources/TimetableWallpaper/AutomationSettingsView.swift), 메뉴 막대·로그인 시 실행·지정 디스플레이 적용을 구현했다. 이번 주 변경 반영, 월요일 주간 전환, 오늘 열의 얇은 테두리를 각각 켜고 끈다. 세 옵션의 기본값은 꺼짐이다.
- 동작: EventKit 알림·60초 확인·날짜/시간대 변경·활성화·잠자기 해제에 대응한다. 의미가 같은 출력은 재적용하지 않고 출처 정보만 갱신한다. 자동화가 관리하는 일정의 삭제를 반영하면서 수동 일정을 보존한다. 주간 교체가 꺼져 있으면 이전 주를 유지하며, 권한/조회/대상 화면 오류 시 기존 적용 기록을 유지한다.
- 구현: 시계에서 계산한 요일을 명시적으로 렌더러에 전달해 결정론을 유지했다. [오늘 표시 예시](../artifacts/today-indicator-demo.png). 저장 형식 v2에 옵션·캘린더 선택·관리 대상·마지막 적용 기록을 포함하고 v1을 기본 꺼짐으로 읽는다. 내용 해시로 같은 PNG 파일을 재사용한다. 일정이 없는 캘린더도 조회·확인 후 연결할 수 있다.
- 검증: 자동화 합성 검사 **79개**, 캘린더 가져오기 **85개**, 렌더러 **28개**, 실제 Apple Vision OCR을 포함한 **47개** 통과. 과거 렌더러의 3개 테마 및 겹침 PNG와 오늘 표시를 끈 새 출력의 바이트 일치도 확인했다. 최신 release 앱 빌드·패키징 및 코드 서명 검증을 통과했다.
- 검토에서 보완: 지연된 활성화 검사가 알림으로 소실되는 문제, 외부 알림의 메인 스레드 전달, 시간대 변경 후 엔진 문맥 갱신, 빈 디스플레이 선택 및 빈 캘린더 연결을 수정했다.
- 한계: 실제 계정 권한·OS 배경화면 변경·로그인 항목 등록은 개발 중 활성화하지 않았다. 합성 provider와 적용기로 오류·자정·주간/DST 경계·오래된 비동기 응답을 검증했다. 앱이 완전히 종료된 동안에는 갱신하지 않으며, 다음 실행 때 따라잡는다. 오늘 표시만 켠 경우 저장된 일정으로 날짜 표시를 갱신한다.

- 결과: [전체 Space 변환기](../Sources/TimetableWallpaper/WallpaperSpaceStore.swift)와 [시스템 설정 저장기](../Sources/TimetableWallpaper/WallpaperStoreWriter.swift)를 추가했다. 모든 Space.Default, Space별 Displays, 공통 Displays, AllSpacesAndDisplays 및 SystemDefault를 같은 이미지로 갱신한다. 기존 화면 보호기 선택과 미지의 메타데이터를 보존하고, 원본 백업·동시 변경 검사·원자적 저장·서비스 재시작 후 검증을 수행한다. 실패 시 자신의 변경만 복구하고 외부에서 바뀐 설정은 덮어쓰지 않는다.

- 저장·자동화: 파생 날짜는 이미지 변경 지문에 포함하되 [저장 파일](../Sources/TimetableWallpaper/SavedStudio.swift)에는 기록하지 않고 매번 연결된 주에서 계산한다. 주간 제목이 꺼져 있거나 일정 내용이 같아도 날짜가 바뀌면 새 배경화면을 만든다. 주간 교체만 켠 기존 작업은 실행·복귀 시 새 표시를 한 번 반영하고, 같으면 추가 조회·적용을 하지 않는다. 모든 자동화가 꺼져 있으면 배경화면을 변경하지 않는다.
